# W2 Day 3 学习心得

## 今天学了什么
- 练习每日提交，形成习惯
- 学习 git reset --soft 撤销提交
- 学会写错 commit message 后如何重来

## 踩过的坑
- 故意写错 commit message 一次，用 reset --soft 撤销重写
- 撤销后改动内容还在，不会丢失

## git show 复习笔记
- `git show HEAD` = 看最新提交完整 diff
- `git show HEAD~1` = 往前 1 次
- `git show 短哈希` = 看指定提交（前 7 位即可）
- `--stat` = 只看文件清单和行数统计

## 明天计划

- 继续每日小改动
